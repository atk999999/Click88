# PK Loạn Chiến — mã nguồn AI Studio

Phiên bản 0.1.44-AJ1. Dự án web React + Vite; thư mục gốc chứa `package.json` và `index.html`.

## Chạy dự án

Trong môi trường hỗ trợ Node.js, cài thư viện và khởi chạy:

```bash
npm install
npm run dev
```

Kiểm tra bản dựng với `npm run build`. Không cần khóa API để chạy game.

## Nội dung chính

- Diệp Tu; Phong Lang và Lôi Ưng; boss Huyết Dự; sáu tia thiên kiếp; Hắc Hỏa Xà; Lăng Tiêu và lựa chọn kiếm kỹ; U Minh Ma Bức; boss Táng Ma.
- Năm ô kỹ năng nhận thêm, 210 công thức dung hợp, hiệu ứng PixelFX và âm thanh lúc phóng, va chạm. 40 công thức mới kết hợp ma kỹ Táng Ma với kỹ năng gốc, quái, huyết kỹ và kiếm kỹ.
- Sau khi thắng Táng Ma, có thể chọn dung hợp ngay hoặc trang bị ma kỹ và dùng nút Dung hợp kỹ năng trên màn hình chiến thắng. Chọn Luyện tập để sử dụng chiêu mới.
- Dung hợp tiêu hao cả hai kỹ năng thành phần; chiêu mới nằm tại ô của kỹ năng đã sở hữu.
- Hình ảnh trong `public/assets`, mã game trong `src/game` và các bài kiểm tra trong `tests`.

Thư mục không chứa `node_modules`, bản build, tệp cấu hình triển khai hoặc các bản demo HTML rời. Khi nhập dự án, giữ nguyên cấu trúc thư mục để game tìm được hình ảnh.
